## 一、语音唤醒（#19 系列）

### 1.1 唤醒词检测
- [x] 主唤醒词命中（叫"汐月"唤醒，Vosk 离线关键词）
- [x] 近似音容错（`variants` 候选词，如"西月""夕月"）
- [x] 灵敏度三档
  - [x] strict：仅主词最终结果
  - [x] standard：主词 + 候选词最终结果
  - [x] loose：+ partial 实时片段
- [x] 唤醒回应个性化（`responses` 随机挑选，可在设置页增删）

**测试点**
1. 设置页 `/settings/services/wake-word` → 唤醒进阶：切换灵敏度三档，分别用标准音/近似音/含关键词的句中词测试命中率。
2. 候选词 / 回应语标签增删后重启，确认持久化生效。
3. 唤醒后角色是否随机说出一条回应语。

### 1.2 唤醒后表现
- [x] 表情动作：唤醒命中 → `surprised` 表情 + `wake` 动作（无对应 motion group 回退 TapBody）
- [x] 紧急停止 Kill Switch：Ctrl+Shift+X → 中断录音/播放 + 角色气泡提示
- [ ] **待接入**：`tool:abort` 事件 → 工具循环（见 #33，🛑 事件已 emit）

**测试点**
1. 唤醒瞬间观察角色表情是否为"惊讶"并播放唤醒动作。
2. 录音中 / TTS 播放中按 Ctrl+Shift+X，确认立即中断且无残留播放。
3. （#33 后）工具执行中按 Kill Switch，确认工具被中止。

### 1.3 主动消息 TTS 朗读（#20）
- [x] 设置页新增「主动消息朗读」开关（角色行为 → 智能闲聊 下方）
- [x] 开关开启时，主动聊天/问候用语音播报（`synthesizeViaBrain` + `audioPlayer`）
- [x] TTS 未配置 / 未就绪时静默降级（仅气泡，不报错）
- [ ] **待实测**：默认 `false`（升级后不突然出声），开启后主动消息确实朗读

**测试点**
1. 设置页 `/settings/models/behavior` → 智能闲聊 下方开启「主动消息朗读」。
2. 等待主动聊天触发（或调小间隔），确认角色气泡 + 语音同时出现。
3. 关闭开关，确认主动消息只显示气泡、不出声。
4. TTS 引擎未启动时触发主动消息，确认不报错、仅气泡。

### 1.4 预制台词管理（#21）
> 入口：设置页 **模型 → 交互消息**（`/settings/models/interaction`）。
> 注意：另有「外观 → 交互」页只管窗口外观（边缘吸附/淡出透明度/点击反馈开关），与台词无关，勿混淆。

- [x] 点击反馈台词编辑：摸头/点身体/踩脚/连点/久未互动 五组，可**逐条编辑 / 新增 / 删除 / 重置默认**
- [x] 闲聊消息池编辑：通用 + 按时段（早/午/晚/夜）+ 按情感（悲/喜/思/怒/羞/孤）分组，可编辑/新增/删除
- [x] 点击语言冷却时间可调（默认 3000ms）
- [x] 预制台词 TTS 开关（开启后气泡 + 语音同时）
- [x] 音频资源：打开文件夹 / 刷新 / 清理孤儿音频 / 重新生成全部（用当前 TTS 模型）
- [x] **单条配音重生成**：点击反馈 / 闲聊每条新增 🔄 按钮，单独重做该条配音，不影响其它台词
- [x] LLM 主动闲聊诊断面板（开关/Key/Provider/今日用量）
- [x] **端到端生效**：设置页改词 → 写后端（Core:9877）→ 模块缓存刷新 → 运行时 `useInteraction`/`getIdleMessage` 立即用新词
- [ ] **待实测**：改一条台词后，实际点击角色确认气泡内容与改后一致

**测试点**
1. 进 `/settings/models/interaction` → 点击反馈 → 展开"摸头反馈"→ 改一条 / 点"添加消息" / 删一条 / "重置默认"，确认保存后不报错。
2. 切"闲聊消息"标签 → 展开某分组 → 编辑/新增/删除，确认持久化。
3. 改一条摸头台词后，**实际去主窗口点角色头部**，确认气泡显示的是你改后的内容（验证端到端）。
4. 开启"预制台词语音"后改词，确认自动重新生成对应音频（设置页音频资源列表出现新文件）。
5. 点"清理未引用音频"，确认旧台词音频被删、当前台词音频保留。
6. 找到一条配音异常/想换声的台词，点其 🔄「重新生成配音」→ 重生成成功后点 🔊 试听确认修复，且其它台词配音不变。

## 1.5 一起看插件（#22）

- [x] `Ctrl+Shift+S` 切换"一起看"模式（开→关 / 关→开）
- [x] 开启后**立即**截屏分析一次，之后每 `watchInterval` 秒（默认 30s，10–120 可调）自动分析
- [x] 分析流程：截屏（Tauri `capture_screenshot`）→ LLM 视觉分析 → 气泡评论 + 表情 + TTS 朗读
- [x] 视觉能力前置校验：未配置 LLM / 当前模型非 vision → 友好提示且不进入模式
- [x] `Esc` 键退出；关闭时停止朗读与定时
- [x] 评论去重：缓存最近 3 次，重复时换兜底句
- [x] 设置页（`/settings/services/multimodal`）可配：总开关、视觉检测 auto/manual、手动视觉标记、截图质量/缩放、**一起看间隔**、**系统提示词**、状态指示器
- [x] 多模态配置持久化（`project/data/config/multimodal`）
- [ ] **待实测**：开启后屏幕内容被实时评论、表情随画面切换、语音念出评论
- [ ] **待实测**：修改提示词 / 间隔后重新开启是否生效
- [⚠️] 注：另有一份 `plugins/watch-together/index.ts` 插件 wrapper（`enabled:false` 默认未启用），与 hook 路径并存属历史冗余，不影响主链路

**测试点**
1. 设置页 `/settings/services/multimodal` 确认多模态总开关开、视觉检测选 `auto`，且当前激活 LLM 为 vision 模型（如 qwen2.5-vl-7b / minicpm-v4.6）。
2. 在桌面播放视频/打开图片，按 `Ctrl+Shift+S` → 确认气泡"好呀，一起看！"且数秒后出现对画面的评论 + 表情 + 语音。
3. 等一个间隔（或调小间隔），确认自动出现下一条评论，且不与前 3 条完全相同。
4. 改设置页"一起看间隔"为 10s、"系统提示词"自定义一句，重新 `Ctrl+Shift+S` 开启，确认生效。
5. 按 `Esc` → 确认停止评论与朗读、气泡"不看了~"。
6. （前置否定测试）把激活模型换成非 vision 模型再开，确认提示"当前模型不支持视觉"且不进入模式。

## 二、刘海字幕声波层（SubtitleNotch）

- [x] 屏幕上方中央刘海位置，默认隐藏
- [x] 覆盖所有说话场景：
  - [x] 唤醒倾听中（`listening`）
  - [x] 识别中 / 识别结果（`recognized`）
  - [x] 流式播放中（`speaking`，按 token 累积驱动）
  - [x] 空闲复位（`idle`）
- [x] 8s 自动淡出 + CSS 声波动画
- [🔧] 视觉细节（位置 / 配色 / 字号 / 淡出时长）待实测微调

**测试点**
1. 唤醒后刘海是否在上方中央出现字幕 + 声波。
2. 语音通话（QQ 式）说话时，刘海是否同步显示"正在说"与文本。
3. 流式回复时字幕是否随 token 滚动更新。
4. 停止说话 ~8s 后是否自动淡出。
5. 视觉反馈：位置是否遮挡角色、字号在 4K/缩放屏是否合适、配色与主题是否协调。
